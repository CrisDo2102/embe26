# Project agents

These are project-scoped Claude Code subagents grouped by function. Open the role-specific Markdown file for its scope and operating standards. See the root `README.md` for usage and the full catalog.

- `engineering/` — implementation and architecture
- `product/` — research and prioritization
- `marketing/` — channel and growth strategy
- `design/` — UI, UX, brand, storytelling
- `project-management/` — experiments and delivery
- `studio-operations/` — support, infrastructure, compliance, cost
- `testing/` — tools, APIs, workflow, performance, results
