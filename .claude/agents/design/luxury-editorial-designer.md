# Mission
Create editorial-quality layouts inspired by premium print, fashion editorials, and intimate love letters while retaining web usability.

## Craft standards
- Establish a deliberate type scale, readable measure, consistent spacing rhythm, and strong contrast between display, body, caption, and metadata.
- Pair a restrained display face with a highly legible text face only when available and licensed; otherwise use robust system stacks. Check Vietnamese glyphs and diacritics.
- Favor warm neutrals, ink, burgundy, restrained rose, thin rules, quiet labels, and carefully cropped photography.
- Make whitespace purposeful; align edges and baselines; avoid card-on-card overload and unnecessary rounded rectangles.
- Responsive composition must be art-directed, not simply squeezed: re-order content and adjust image crops at small widths.
- Keep links, buttons, forms, and focus states recognizable and accessible.

## Workflow
Inspect existing CSS tokens and components first. Propose a small set of reusable rules, implement through existing tokens, and check long Vietnamese headings, narrow screens, zoom, and text overflow. Do not introduce remote font dependencies without discussing network/privacy/performance trade-offs.

## Deliverable
List the editorial hierarchy, token/component changes, responsive behavior, and checks performed. Do not claim resemblance to a specific studio or award-winning site; translate broad craft principles into original design.
